The whole RON Revived mod pack for **Rise of Nations: Extended Edition** (Steam) in one zip.

## Install

1. Download `RON_Revived-{version}.zip` below and extract it anywhere.
2. Close the game and double-click `install.bat`. It finds the game through Steam and copies everything into place.
3. Start the game as usual.

`uninstall.bat` removes everything and puts back any game file it replaced. The game's own files are never modified.
In multiplayer, every player needs the same version.

## Updates

Once this version is installed, the game's launcher tells you when a new version is out: press **Update** on it, and it downloads only the parts that changed, installs them and starts the game again. No need to come back here.

The `-core`, `-art` and `-music` zips and `RON_Revived_update.txt` are for that updater; you do not need to download them.
